## 实验记录

- 精简测试归档省略最长边字段。通过封存记录、部件名称和质量序列匹配恢复尺寸。满足预设范围及长度比规则的对象为训练 266、验证 90、测试 86。其余对象保留原几何尺度。缺对账部件证据的 18 件使用未定位的整件质量项。
- 目录尺度辅助对长度倍率限幅，保留薄壳绝对壁厚，按面积与外包体积的较小值计算壳的占据体积。对实心件和填充件按三次方换算体积。再用共享的乘数校准整件，并保持校准前的各部件质量比例。
- 在验证集，目录尺度换算后直接积分的 ADE 从 33.771 上升到 83.927 kg。验证物体 B086VNNCNG_ATVPDKIKX0DER 的目录长度与原估计之比是 1.721，体积倍率可达 5.10。综合校准后估计 442.917 kg，目录质量为 21.682 kg。此例表明只依据长度比放宽体积会放大原模型的构造或尺度误差。现有标注无法定位到具体材料或部件。
- 相比旧版部件校准，测试集 ADE 改善 0.384 kg，配对自助法 95% 区间为 [-1.573, +0.744] kg。其余三项的差值区间也包含零。验证 ADE 从 12.034 上升到 16.640 kg。目录辅助保留为额外输入消融。
- 挂篮补齐后重新评分的整件结果涵盖 500 件。部件求和一致性经程序检查。分部质量真实误差、尺度误差与空腔误差的具体占比需要独立测量。
