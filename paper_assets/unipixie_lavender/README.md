# UniPixie 植物资产定位和紫花试算

紫花在 PixieVerse 公布的检索元数据中有唯一一条 lavender 描述，Objaverse UID 为 18f5fba66f944aad9ae84ea2172b9b78。模型为 Eryn_Noel 的 Assignment4_Flowers，CC BY。作者预览的花序和叶片与截图吻合。GLB 由 Objaverse 获取并记录哈希，渲染使用原模型的纹理。对照页面未找到这一行的 UID 映射或逐帧数值，所以同源认定依赖描述和外观。常绿树有多个近似候选；b88cbf315f2449aea533598f20da62b7 外观相近，尚无足够证据确认它是截图模型。

这个视频是重新计算的条件试算。按原资产五个网格节点估计梁长，设整株高度 0.45 m，等效半径 2.5 mm，模量 90 MPa，密度 650 kg/m³，受风宽度 8 mm。以 1 m/s 峰值阵风驱动阻尼悬臂梁，结果中最长节点的峰值挠度约 13.58 mm。模量、密度和载荷均为设定参数。试算用于演示数据到原纹理网格动画的流程。UniPixie 的同物体逐点物性、基线参数及真值轨迹仍待取得。
