# ABO-500 纯结构 APE 诊断

完整 300／100／100 在服务器重跑。三组均读取相同归档网格和结构记录，不调用视觉估重头或目录尺寸。调参只读训练集折外预测及训练真值。该测试集此前用于开发诊断。

22 件低于 1 kg 的测试对象中有 19 件被高估，贡献原 APE 总和的 63.1%。前五个最大百分比误差贡献 53.5%。逐对象记录表明，网格占据过量与回归放大均存在。

- B003QTD4Y6 目录 0.091 kg，结构积分 0.413 kg，其中按实心橡胶处理的边缘占 0.270 kg。原回归又升到 2.168 kg。应检查边缘截面及材料体积。
- B003LSTD38 目录 0.100 kg，结构积分仅 0.041 kg，原回归升到 0.879 kg，应核查回归是否把小型壳体向训练物体的常见重量推高。
- B07F3T4RSD 目录 0.370 kg，原积分中网布外壳占 0.952 kg。应使用展开面积、面密度和网孔信息复查，格栅和织物的面积比例与基材密度需一致。

## 修正

轻物体训练权重使用训练中位质量除以物体质量的 1/4 次方，截断至 [0.25, 8]。同一 Extra Trees 模型族重训。对训练折外输出尝试按预测质量平滑减重，并尝试以小结构积分为依据进行上限限制。候选必须满足训练折外 ADE 上升不超过 5%，ALDE 上升不超过 10%，再从满足者选择 APE 最低。选中轻物体加权，校准转换为 `m * (1 - 0.45 / (1 + (m / 3)^2))`。未选中积分上限。校准仅调整整件，部件按原有质量份额同比例变化。
