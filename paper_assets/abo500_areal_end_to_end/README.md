# ABO-500 篷布修正的完整流程复验

使用原 300／100／100 划分。在服务器重新训练纯结构和纯图像并评估融合。所有 500 件均有三个模型的结果。本轮使用统一部件账本和已定义的篷布异常敏感性规则。纯图像与融合不使用商品目录尺寸。

## 参数

- 布层。仅在开架分支的篷布面密度大于 1350 g/m² 时，替换为 250 g/m²。规则影响测试一件。
- 结构。Extra Trees 128 棵树，最小叶样本 2，候选特征比例 0.7，训练质量权重指数 0.0。
- 图像。三视图 00／08／20，ViT-B/16 特征归一化后取均值再归一化。对数质量岭回归 alpha = 0.1。
- 融合。结构对数权重 0.25，结构与图像预测质量的比限制在 [1/3, 3]，结构证据缺失的候选回退参数为 0。本轮 500 件均有已核验部件记录，无此回退触发。
- 训练。固定五折，随机种子 25。训练表使用折外预测。融合选参按三项误差相对于纯图像的平均比例。测试集此前用于误差诊断。

## 对照结论

唯一因篷布参数改变而改变纯结构预测的物体是 B07YLYRSB6_ATVPDKIKX0DER。原始物理积分为 38.924 到 18.611 kg。相同纯结构模型的输出由 19.046 变为 19.877 kg，目录值为 18.280 kg。原始积分误差大幅减少，回归头未获得进一步整件收益。纯结构测试 ADE 从 5.218 变为 5.226 kg。

已发布的融合试验（4.976 kg）采用旧版结构输入。本轮融合 ADE 为 4.942 kg，ALDE 与 APE 较此前略高。两轮同时更换了部件账本输入，差值包含账本修复影响。
