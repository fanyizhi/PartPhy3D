## 问题和处理

- 先用每个原始部件的材料、构造和质量校准各部件，再用目录最长边和旧网格最长边的比例计算该部件的体积倍率。保留壳壁厚。训练选中的修正为原体积倍率开平方，结果限制在 0.5 到 2，再乘该部件校准质量。参数按训练集 ADE、ALDE、APE 相对旧部件模型的平均误差比例选出。
- 验证 90 件、测试 86 件的结果受到这项修正影响。验证 ALDE 配对差异为 −0.101（95% 区间 [−0.165, −0.036]）。测试 ADE 配对差异为 +0.305 kg（95% 区间 [−0.705, +1.396]）。测试集其余三项的差异区间也包含零。
- 验证个案 B086VNNCNG_ATVPDKIKX0DER 的目录质量为 21.682 kg。上轮目录尺度方案估计 442.917 kg，本轮估计 67.650 kg，逐部件基础校准为 33.825 kg。五个部件在本轮均触及放大上限，说明后续需要重新核对框架截面和填充占据量。
- 已核对 500 个唯一 ID 和每个对象的质量总和。其中 482 件可以对账到具体部件，18 件以未定位整件项计。数据标注提供整件质量。部件质量与编辑结果的准确性仍需单独的实测验证。
