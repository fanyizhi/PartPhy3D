# 结构质量修正的可信度实验

冻结模型在验证集上较图像先验增大了平均绝对误差。为检验两条质量通道分歧较大时是否应削弱几何贡献，取图像估计 I、投影后结构估计 P 和冻结融合估计 F。新估计为 I × exp[exp(−k |ln(P/I)|) × ln(F/I)]。缺少结构估计时回退至 I。

用前七批已封存训练对象（175 件）最小化对数残差的 pseudo-Huber 损失，在 [0,4] 拟合一个参数。原图像头已用 300 个训练对象拟合，因此这 175 件的先验属于训练内预测。验证集沿用原来的 100 件。测试集未参与此次比较。图像行使用本次同一推理记录内的先验，先前主表使用 CPU 重放的先验。

|验证集方法|ADE kg ↓|ALDE ↓|APE % ↓|MnRE ↑|
|---|---:|---:|---:|---:|
|冻结融合|12.420|0.6880|83.61|0.5738|
|本次图像先验|11.488|0.6717|91.22|0.5811|
|按分歧衰减|11.472|0.6712|91.37|0.5816|

拟合值 k=4 达到搜索上界，新结果接近图像先验。以对象为单位做 10,000 次配对 bootstrap，ADE 差值的 95% 百分位区间为 [−2.39, 0.28] kg，其他三个指标区间也都跨零。APE 上升 7.76 个百分点。当前证据不足以替换主方法。下次应使用训练折外的图像先验估计融合权重，并对承重件是否空心引入可观测的结构证据。
