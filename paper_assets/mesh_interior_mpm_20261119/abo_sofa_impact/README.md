# ABO-500 灰沙发 MLS-MPM 接触试验

案例为 Amazon Berkeley Objects 渲染对象 B07QFP4PV5_ATVPDKIKX0DER。图 a 为第 00 帧。图 b 叠加已有六视角重建网格与截去一半后的内部材料点。粒子来自项目的外层织物、泡沫与木支撑假设，保留逐点密度、代表体积和质量。刚度和泊松比分别为织物 100 MPa / 0.33、泡沫 2 MPa / 0.25、木材 10,000 MPa / 0.30。分材料域的赋值依据与网格来源见[原始构造记录](../../../docs/results/mesh_interior_mpm_20261119_zh.md)。

在初始最低粒子位置设置无摩擦地面节点，整件物体以 2 m/s 向下初速度起算。3D MLS-MPM 背景网格为 123 mm，固定时间步 4.8 μs，推进 800 步并每 20 步保存粒子位置。消融固定几何、质量、粒子位置及边界条件，把每个粒子的杨氏模量和泊松比统一为泡沫参数。

图 c 按 1 倍显示实际计算位置，颜色表示去除质心平移后各点的位移模长。图 d 为质量加权均方根总位移，游标与左图模拟时间对应。该工况检验导出的材料参数是否改变短时接触响应。背景网格粗于 5 mm 的布层，内部构造及本构是条件假设，案例缺少实物碰撞轨迹和薄层分辨率收敛数据。
