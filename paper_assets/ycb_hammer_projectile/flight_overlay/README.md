# 扫描锤的质心与几何中心全程轨迹

三列使用同一 YCB 048 扫描网格、同一相机、原比例及同一组起抛冲量。均匀组和钢头组同质量；铝头组只替换头部密度，锤柄及网格保持一致。红色实线追踪各组计算质心，蓝色虚线追踪同一个物体固定点，即体素积分的几何体积中心。各列的半透明姿态来自 MuJoCo 逐帧状态。地面为可视参考；首次有凸包顶点穿过地面的前一时间步为各列停止时刻，因此画面展示空中段，即不包含触地反弹。

均匀组的几何中心和质心重合。钢头组的两个中心相距 83.33 mm，随物体旋转，几何中心相对其质心的偏移在世界坐标中改变方向。铝头组的中心间距为 42.74 mm。钢头和均匀组在相同初速度下，质心的相对弹道一致。铝头组的总质量降低，同线冲量给出的初速度改变，质心抛物线随之改变。均匀、钢头、铝头组最后一个空中帧分别是 0.664、0.703、1.165 s。

真实扫描用于几何。钢头组质量来自基于体素的材料积分，高于 YCB 公开实测质量。三组缺少同一工况的实拍真值，无法由轨迹直接判断哪组吻合实物。该对照用于说明几何中心、质量中心和换材对运动的不同影响。资产许可及质量偏差见[父实验说明](../README.md)。
