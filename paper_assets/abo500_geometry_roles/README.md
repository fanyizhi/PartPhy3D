## 实验记录

- 板件使用双面面积近似，圆杆使用侧面积乘直径的四分之一，薄层使用分配面积乘厚度。角色由部件名称及材料约束识别。面积来自原模型分配。厚度、直径及最大削减量只用训练集选定。修复单复数匹配后，床架错误由 95.41 kg 降到 50.47 kg，目录为 36.70 kg。装配内部、实际截面与材料实测仍需核对。
- 体积约束改变 122 件。测试 APE 相对逐部件校准降低 17.64 个百分点，配对 95% 区间为 [−42.72, −1.23]。验证 ADE 从 12.03 升到 12.42 kg。
- Extra Trees 从结构特征回归整件对数质量。目录辅助版本额外读取目录最长边。部件总和通过按结构原有质量占比分配保持。分配结果未接受单部件标签验证。
- 训练加权候选通过原训练折比较。目录辅助版选中重量反比的四分之一次方，权重截到 [0.25, 8]。在测试组，APE 相对等权版本降低 13.08 个百分点，配对 95% 区间为 [−25.82, −3.03]。22 件低于 1 kg 的物体 APE 从 264.99% 降到 210.08%。同一加权方案使验证 ADE 从 9.09 升到 9.83 kg。
- 目录辅助加权版仍有两项落后于各论文的最低报告值，ADE 4.960 kg 对 PhysVGGT 的 4.730 kg，APE 77.10% 对 PUGS 的 76.70%。整件质量回归与物理分部实验提供不同证据。原论文划分与输入也各有差异。 [五篇基线原文及口径](../structure_study_20261126/README.md#五篇论文报告的质量指标)
