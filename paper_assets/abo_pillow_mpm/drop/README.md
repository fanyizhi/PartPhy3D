# ABO-500 靠枕的下落与弹性响应

输入为 ABO-500 验证集对象 B074VM1T62 的第 00 帧。两组复用此前从该物体的重建网格经自适应采样导出的 7,689 个材料点。织物与泡沫的几何分区、质量、密度、泊松比、接触与积分设置匹配。对照只将各粒子的杨氏模量乘以 0.25。其作用是检验同一材料分配在刚度改变时的响应差异。

自由落体段用解析轨迹，释放高度由原接触试验的 3 m/s 入射速度反算，接触段用 MLS-MPM 重跑。视频在切入接触后缩小取景范围，两段都使用 1 倍实际位移并延缓播放。动态画面显示沿初始中心窄带选中的材料点，其位置来自逐帧轨迹。右图的压缩量是初始竖直包络高度减去当时全体粒子的竖直包络高度。负值对应包络高于初始状态。

织物和泡沫域内采用各自的常数先验。材料之间保留不同参数。材料点数量以及逐材质的密度、模量、泊松比和质量见数值记录。该试验展示分区赋值可以产生可复核的动力学响应，材料布局和响应准确度仍需实物剖面与落地轨迹验证。
