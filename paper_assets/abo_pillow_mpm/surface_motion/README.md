# 靠枕重建表面的动态展示

对象为 ABO-500 验证集条纹靠枕 B074VM1T62。画面中运动的靠枕是这个对象的六视角重建三角网格，沿用重建时保存的顶点颜色。画面两列使用同一个网格、质量、相机与释放条件。右列只把各材料的杨氏模量设为左列的 25%。

释放高度 0.459 m 由原接触实验的入射速度 3 m/s 反算。自由落体段采用解析轨迹。接触后的 12 ms 采用已核验的三维 MLS-MPM 轨迹。对每个网格顶点，使用最近的八个织物粒子的位移，按初始距离的平方倒数取加权平均。保持三角面拓扑和顶点颜色。两组的显示倍率均为一倍。接触时切换近景并慢放。画面数字表示全体仿真粒子的竖直包络压缩量。

这是从数据集外观重建后以预测属性驱动的模拟画面。ABO 提供物体外观；该物体没有配对的实拍掉落视频。内部泡沫、织物壁厚与模量属于构造先验。
