# ABO-500 条纹靠枕接触仿真

对象 B074VM1T62 来自 ABO-500 官方验证集。使用第 00 帧作图、既有六视角重建和封存构造记录。重建的绕向已修复。将其短轴旋转至竖直方向，使用构造记录的最长边 0.50 m 换算至米。模型提出 2 mm 织物外壳和泡沫填充。接缝材质与外壳相同，本次简化为单一外层。泡沫内芯与壁厚待实物验证。

程序依据网格有符号距离自适应采样，在物体边界和壳芯界面加密，再按材料保守合并粒子。织物取 350 kg/m³、100 MPa、泊松比 0.33，泡沫取 65 kg/m³、2 MPa、泊松比 0.25。使用三维 MLS-MPM、34 mm 背景网格、8 μs 时间步和无摩擦地面条件，初始向下速度为 3 m/s。此网格支持物体尺度响应的初步验证，薄织物的局部应力仍需专门的网格收敛实验。

动图画面显示靠枕的中央材料点薄层。灰线为投影粒子轮廓的凸包。位移按一倍显示。包络高度采用全体粒子的竖直极差，包含极值粒子运动，属于计算诊断。

本次结果为 7,689 个材料点、51 帧和 12 ms 计算时长。粒子包络高度从 165.53 mm 压至 163.77 mm，随后出现衰减振荡。这是小幅变形。空间积分模拟质量为 1.684 kg，与此前基于构件份额的 1.031 kg 相差 0.653 kg。两种积分对泡沫占据体积的定义不同，需在后续质量验证中核对。部署时隔离安装 libigl 2.6.3，并同步本地的采样器与 MPM 求解器。下载后检查全部帧为有限值，并逐粒子验证质量等于密度乘体积。
