# 山毛榉层积材真实荷载与形变曲线

来源为 Töpler 与 Kuhlmann 的 DaRUS 开放数据，DOI 10.18419/DARUS-5058，CC BY 4.0。选用公开表格 S03、S04、S05 的 Aramis 工作表。该工作表逐点记录同步的试验机轴向荷载和数字图像相关法测得的跨中横向位移。剔除非数值表头，保留原序列、单位与记录中的符号。以记录中的峰值载荷分开两段，绘图未平滑。图用同一坐标范围，样件可能具有不同几何和设置，峰值差异不能归因于材料模量一个因素。

源数据可用于后续的结构荷载响应验证。当前稿件报告公开实验的测量曲线及峰值，样件几何、初始弯曲、支座和独立模量需与预测模型一一配对后，才能检验模量和仿真精度。
