# ABO 沙发在 MuJoCo 中的质心与刚体轨迹

同一 ABO-500 彩色重建网格和 4,492 个已导出的材料点。分材料组质量来自原逐粒子分配。均匀组保持原粒子位置与代表体积，使用相同总质量除以总体积作为统一密度。两组各自积分质心和中央惯量张量，输入 MuJoCo。质量点生成与材料参数见[沙发构造记录](../../docs/results/mesh_interior_mpm_20261119_zh.md)。

两组绕同一个水平轴从 28° 静止释放。铰链位于均匀组初始质心上方 210 mm。重力是唯一驱动力。图左显示同一表面网格和计算质心，右图绘制质心路径及摆角曲线。模拟步长 1 ms，画面追踪 1.6 s。构件分界、质量和惯量的真实值待独立测量。这是铰链工况，参考 Gen2Physics 使用 MuJoCo 比较材料分配和均匀密度的思路。其图 1 使用另一物体的自由落体。两篇的轨迹数值不直接对比。

| 指标 | 分材料赋值 | 同质量均匀密度 |
|---|---:|---:|
| 总质量 (kg) | 40.278 | 40.278 |
| 未旋转质心高度 (mm) | 353.99 | 366.93 |
| 绕共同铰链的转动惯量 (kg·m²) | 5.496 | 5.009 |

质心空间距离为 17.40 mm，摆角最大差为 6.10°。独立刚体常微分方程与 MuJoCo 的最大角度偏差小于 4.3e-11 rad。H.264 导出初次遇到奇数像素高度，重设画布采样后通过。
