# ABO-500 网布与包边体积诊断

服务器沿用固定 300／100／100 重新执行结构积分、纯结构估重、纯图像估重和融合。结构与图像均使用三视图或其派生数据。新规则候选使用训练标签，回归参数通过训练五折选择。该测试集曾用于误差诊断。

- 网布使用归档的分配面积乘面密度，作为原物理质量的上限。包边使用分配面积乘等效厚度与密度作为上限。训练选出网布面密度上限 250 g/m² 与包边等效厚度 3 mm。15 件具有可用部件证据并符合规则，3 件的物理积分改变，训练、验证和测试各一件。实际变更均来自网布。参数是模型假设，需要材料和截面实测校验。
- B07F3T4RSD 的原积分 0.971 kg，新积分 0.359 kg，目录质量 0.370 kg。纯结构整件回归从 4.720 kg 降到 3.379 kg，仍大幅高估。网布修正见效的阶段是物理积分，回归对该轻物体仍存在放大。
- 与同对象的前版比较，新纯结构测试 APE 下降 3.60 个百分点，自助抽样 95% 区间 [−11.52, +1.08]。报告回归分数，不把原始物理积分混进模型比较。
