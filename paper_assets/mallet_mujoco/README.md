# 木柄橡胶锤的质心与刚体运动

该算例使用可解析的双构件几何，木柄和橡胶头是两个相接、无体积重叠的长方体。两组共用形状、体积分点、总质量、铰链和 28° 静止释放条件。分材料组用项目木材密度 650 kg/m³ 和橡胶密度 1100 kg/m³。均匀组使用总体积和总质量得到同一密度。解析质心由两个长方体按真实设计质量加权得到。材质分区为设计输入。该算例验证已知材质下的粒子积分和参数传递。

| 指标 | 分材料赋值 | 同质量均匀密度 |
|---|---:|---:|
| 总质量 (kg) | 1.242688 | 1.242688 |
| 质心距手柄底部 (mm) | 314.146 | 299.585 |
| 相对解析质心的误差 (mm) | 小于 0.001 | 14.560 |
| 绕共同铰链惯量 (kg·m²) | 0.02042 | 0.02716 |

1.6 秒内最大摆角差 22.59°。两组 MuJoCo 轨迹分别与利用同组质心、转动惯量和重力的独立方程对齐，角度残差均小于 1.8e−10 rad。结果支持材料质量分配会改变质心和转动。该算例受固定铰链约束。Gen2Physics 图 1 的案例为自由落体，两者的轨迹设置不同。
