# 局部换材及 MuJoCo 抛投验证

设计样件由木柄和锤头两个不重叠的体域构成。使用项目材料先验，木柄、橡胶和铝的密度分别取 650、1,100 和 2,700 kg/m³。编辑记录以部件 ID 定位锤头，原几何和木柄参数随同一构件记录保留。程序从体域尺寸和材料密度重新积分构件质量、整体质心和惯量，将结果直接导出到 MJCF。这个设计件呈现部件替换如何向下游传播，部件划分由设计给定。

原始同质量对照以同样的质心初速度起抛，解析质心轨迹重合。材料编辑对照改用相同线冲量与角冲量，原件和改材件的起抛质量与惯量各自参与计算。两组编辑轨迹初始质心高度为 0.78 m，线冲量沿水平与竖直方向的分量为 1.6155 和 3.2310 N·s，绕横轴角冲量为 0.061 kg·m²/s。飞行段只受重力，共 0.45 s。两物体沿横向分开方便观察，曲线坐标均以各自的发射位置为参照。地面提供视觉背景。这一工况结束于落地接触前。

| 指标 | 原橡胶头 | 换铝头 |
|---|---:|---:|
| 总质量 (kg) | 1.242688 | 2.796096 |
| 质心距柄底 (mm) | 314.146 | 329.065 |
| 横轴中央惯量 (kg·m²) | 0.007889 | 0.009966 |
| 水平起抛速度 (m/s) | 1.300 | 0.578 |
| 0.45 s 水平位移 (m) | 0.585 | 0.260 |
| 0.45 s 姿态角 (°) | 199.37 | 157.81 |

左 panel 直接由 MuJoCo 渲染，右 panel 显示质心弹道和姿态角。两组 MuJoCo 质心轨迹与各自解析抛物线的最大位置误差约 3.9×10⁻¹⁵ m。该误差验证了仿真边界条件和数值坐标。真实材料参数及实拍运动仍需独立验证。
