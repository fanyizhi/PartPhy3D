# ABO-500 纯结构残差回归复验

在服务器按固定 300／100／100 运行全部 500 件。结构模型输入来自同一部件账本与篷布敏感性回放。对照使用相同结构特征。新分支拟合 log(整件目录质量／原物理积分质量)，预测时乘回物理积分。使用训练五折选参，测试集此前用于误差诊断。

模型为 Extra Trees，128 棵树，随机种子 25。训练选中最小叶节点 2、每次分裂使用全部候选特征及等权样本。对照和低质量校准来自上一轮同对象预测。

## 结果解释

测试的 22 件低于 1 kg 的物体，APE 从 299.02% 降到 275.13%。整组 APE 下降 1.14 个百分点，配对 95% 区间为 [−22.02, +15.69]。测试 ADE 上升 0.115 kg，ALDE 上升 0.046。残差形式保留积分尺度，但现有物理积分中的误差也会传入结果。模型输出中的分部质量按已有部件比例分配，500 件逐件求和已核验。
纯结构主对照继续使用直接回归。若单看降低 APE 的实验，则上轮的低质量段校准分数更低，同时存在 ADE、ALDE、MnRE 的取舍。
