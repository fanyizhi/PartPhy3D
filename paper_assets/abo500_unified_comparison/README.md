## 处理和核验

- 补齐上一轮缺少的第 100 件的图像分数。重新提取 500 件每件三帧的图像特征，校验帧文件和模型权重哈希。三个模型使用训练折外预测比较候选，训练和验证测试数据未混合。测试集过去用于误差诊断。
- 融合对结构与图像质量比限幅至 1/3–3，再以训练选定的 25% 对数结构权重修正图像值。测试相对纯图像 ALDE 差为 −0.0404，配对 95% 区间为 [−0.0687, −0.0123]。MnRE 差为 +0.0159，区间为 [+0.0005, +0.0310]。ADE 与 APE 的区间包含零。
- 扫描 172 个通过封存校验且按对象列表储存的预测归档。18 件没有找到与最终结构质量严格对账的部件候选，分别是训练 6、验证 2、测试 10 件。它们保留整件结构估计。强制回退至纯图像时，测试四项为 4.943、0.538、73.80%、0.644，但训练折外的综合误差更高，保留为诊断。
- B07Y2B738L 的归档整件结构质量约 10.85 kg，另一归档版本的部件合计约 216.58 kg，其中内部壳体约 212.88 kg。候选构造缺少与最后积分版本一致的局部体积证据。以实物尺度重分壳体和内部组件后才能恢复分部质量。
