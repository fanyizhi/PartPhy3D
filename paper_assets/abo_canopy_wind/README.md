# ABO-500 蓝色遮阳棚的风载响应

对象 B07YLYRWJ7_ATVPDKIKX0DER 来自 ABO-500 训练划分。用第 00 帧、原六视角重建及封存构造。以重建顶点颜色定位蓝色棚布，材料类别则取自封存构造。保持原网格和颜色。支架与棚缘固定。织物密度 350 kg/m³，杨氏模量 100 MPa，采用构造记录中的 2 mm 等效厚度。该厚度与同记录中旧包络分支的 0.05 mm 不同，本实验使用分组薄片记录。应以实物厚度测量判别哪个假设更接近。

用等效张紧膜第一模态做降阶求解。织物面密度为 ρt，预张力取 Etε。预应变 ε 为 0.001，模态阻尼比 0.16，均为设定工况。以 12 Pa 峰值净压力模拟阵风中的屋面平均载荷。载荷在 0.20 至 1.65 s 内按正弦平方变化。不是流体仿真，未求解绕流和褶皱。原网格蓝色顶点沿竖向按膜模态位移移动，非棚布顶点保持固定。视频显示一倍位移。专业图同时显示对象、载荷、位移和同一时刻游标。
