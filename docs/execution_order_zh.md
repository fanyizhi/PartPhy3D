# 一个物品的实际处理顺序

当前逐步输入、输出和验收以 [2026-11-03执行流程](current_pipeline_2026-11-03_zh.md) 为准，采用InstantMesh固定前端。先10物体后完整数据集；以下保留总体目标流程，不表示每项均已实现或必须纳入首篇论文。

最新已运行的十物体开发实验、真实数值和复现命令见`docs/ten_object_experiment_2026-10-30_zh.md`。以下步骤描述总体目标流程；各模块的实际完成状态以该实验记录为准。

1. 输入是物体真实照片、多视角与相机/尺度信息；不是先画论文属性图。质量标签保存在独立评价数据中。
2. 使用InstantMesh固定权重生成初始Mesh，再用声明的图像、相机和尺度证据对齐校准。参考Mesh仅作独立诊断/几何参考，主路径不得暗中依赖其几何。当前10物体原型直接使用官方GLB，尚未执行InstantMesh。
3. 检查单位、法向、孔洞与连通片；建立真实图像与Mesh表面的空间对应。没有足够真实视角时，可从Mesh渲染几何/纹理图作为辅助，但不能把生成视角当成新增真实证据。图像预处理、裁剪或缩放后应同步更新相机参数。
4. 在完整Mesh上做层级分割，得到逐面部件标签、材料区域与局部连接候选。此时导出的部分Mesh通常只是开放的表面片，不可直接当作独立封闭实体积分。
5. 将多视角证据、部件身份、局部几何、材料、构造候选与连接关系绑定到统一表示中。用预先训练/微调的融合与分布预测模块推断材料和内部结构。模型训练是独立的离线阶段，单物体推理时不应重新训练整套模型，也不应使用测试物品质量。
6. 构建可积分的体积域，在其中分配材料与空腔的占用率。可以使用共享体积场，未必需要把所有部件生成成独立封闭Mesh。若需独立部件用于仿真，才增加补全、封闭性与相互重叠检查，防止重复计算质量。
7. 在同一空间质量分布上计算部件与整物体质量、质心、惯量及其区间。E/nu、摩擦、硬度等有各自监督与适用条件，不能从总质量反推出全部参数。
8. 可选执行物理敏感度驱动减面、属性迁移、部件编辑或仿真导出。编辑改变材料或结构后重算质量，而同一物体的表示迁移应控制质量矩变化。
9. 使用独立真值评价，最后生成属性、内部剖面、连接近景、质量对比、校准、效率图和参数/指标表。连接几何检查与真实连接强度评价分开。

文件名在框图中表达目标输出契约，不表示现有全部模块已经实现。现有最小示例采用参考Mesh、几何/模板分组和人工构造先验；真实学习式融合、内部后验和力学可靠性仍需要实现与独立实验。
