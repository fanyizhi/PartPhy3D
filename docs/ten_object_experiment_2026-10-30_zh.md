# ABO-500十物体批量开发实验

日期：2026-10-30。主结果目录：`outputs/abo500_ten_v2`。

## 1. 已完成的范围

固定选用发布版test列表前10个ID，没有按质量误差筛选或替换对象。10个Mesh均已从ABO官方源取得；10/10通过预设的多视角对应检查并完成预测、评价和图表导出。

本轮运行原始Mesh＋数据集alpha轮廓＋共享几何/颜色规则＋缓存语言材料建议＋人工构造先验。没有执行InstantMesh、Qwen、PartField/SAM或QLoRA训练，也没有复现PUGS、NeRF2Physics和PhysVGGT。

本轮将贵妃椅专用规则替换为跨对象共享的几何区域聚类与构造规则。第一件贵妃椅已在上一次实验开发中使用，所以报告10例总结果及去掉该物体的9例结果。整个小样本属于开发诊断，不能称为最终独立测试基准。

## 2. 实际流程

1. 保存固定选择清单、配置、图像/相机/模型/缓存建议校验值。
2. 原始Mesh固定从glTF Y-up变换到数据集Z-up，相机尺度保持原值；使用30视角轮廓IoU检查对应关系，门限0.85。
3. 位置、法向和纹理颜色聚类，邻接平滑，最多8个几何区域。区域编号不冒充语义部件或制造零件。
4. 在标定视角的轮廓交集中建立米制体积域，结合原生连通片包围盒进行几何支持裁剪。凹陷、薄壁、开放组件仍可能产生偏差。
5. 根据缓存描述与统一规则选择构造类型，抽样表面材料假设和宏观内部占用；候选密度范围保留来源，缺失内部材料使用显式记录的全局先验。
6. 材料类别概率用于抽样假设，与材料体积占用分别表达。4096次采样在各区域间共享材料密度变量，区间未校准。
7. 按96/144/192三个请求分辨率检查离散敏感性，144固定作为主结果。总格点预算可能使实际分辨率受限，因此逐对象保存实际pitch。
8. 积分整物体和区域质量、质心及完整惯量，保存NPZ、区域状态JSON与参数CSV。
9. 生成约50%、25%面数的QEM候选，并把原面标签映射到减面Mesh。质量继续使用原体积状态，零变化由状态复用保证，不是独立物理精度证据。
10. 所有预测先保存并校验，再打开质量标签统一评分。最后输出每物体及总体图表、局部属性待测模板。

第一轮检查发现自动聚类边界被误用作壳体边界的问题。修正为对整个体积包络计算距离后，重新运行全部10例；该修正发生在首次打开另外9个对象质量标签之前。早期原型保留在`outputs/abo500_ten`，最终记录在`outputs/abo500_ten_v2`。没有依据评价结果重新拟合材料、占用或质量比例。

## 4. 这轮实验暴露的问题

- **区域不是部件**：几何聚类会跨越真实材料或把同一部件分成多个区域，区域映射还不能替代精细部件模型。
- **外观材质存在歧义**：白色涂装木材、金属、塑料等在启发式颜色分类下混淆；少量高密度材料假设就会显著影响平均质量。
- **内部构造尚属先验**：电子件内部、软包骨架、包体空腔及哑铃内芯都需要更可靠的构造推断与监督。
- **几何离散尚不稳定**：5/10对象的144到192请求分辨率质量变化超过5%；柜子约21.89%、装饰框约14.67%。原生包围盒不是精确体积，薄壁与开放表面需要更合适的厚度/封闭模型。
- **区间缺乏校准**：10例中只有2个标签位于构造先验的90%区间内。这个小样本命中比例只作描述，不能宣称90%覆盖保证。

这轮支持的结论是“通用化基线已经可运行，并明确暴露关键误差来源”。尚未证明论文拟议方法有效，也未获得真实局部物理属性准确性证据。

## 6. 实际耗时与验证

本机CPU最终预测阶段132.23秒；包含30视角对应、三个体素分辨率、4096次采样和两档QEM。全套最终图表约38.32秒。下载/缓存、代码开发、测试与首次环境准备另计。这不是两张4090的测速，也没有包含InstantMesh/Qwen运行。

16项相关自动化检查通过，含材料范围解析、显式回退来源、组件间空隙保护、有限体积积分与采样一致、物体级指标、人工区域边界不产生额外壳层、局部属性评价和原有体积/质量隔离检查。静态检查通过；总图与代表性单图已检查标签、色标和裁切。

预测源码快照与冻结SHA一致。最终源文件之后只增加绘图色标、结果诊断及模板导出；预测函数和推断参数不作标签后调整。体积字段和预测校验保持不变。

## 7. 复现命令

在已安装项目的Linux环境与项目根目录中，把`ABO_ROOT`设为真实数据集路径；采用新输出目录保留原始记录：

```bash
export ABO_ROOT=/服务器上的实际路径/abo_500
export PYTHONPATH="$PWD/src${PYTHONPATH:+:$PYTHONPATH}"
python scripts/prepare_ten_objects.py \
  --root "$ABO_ROOT" --assets data/abo500_ten --output outputs/abo500_ten_reproduced
python -m tactile3d.experiments.ten_objects \
  --root "$ABO_ROOT" --assets data/abo500_ten \
  --config configs/ten_object_pilot.yaml \
  --output outputs/abo500_ten_reproduced --stage all
```

`--stage all`可拆成predict、evaluate、plot三个阶段。没有GPU也可重现当前基线。若要执行真实InstantMesh、Qwen及学习式分割，仍需接入GPU运行环境与对应模型；这些不能由当前结果替代。
