# 方法与结果逻辑链

> 历史方案。2026-10-30已将“部件可编辑”提升为论文核心，当前方法与贡献以 [IEEE Transactions修订方案](ieee_trans_method_contributions_zh.md) 为准；本文件保留早期探索记录。

主问题：在部件边界和内部构造不确定时，如何建立能在细化、简化和编辑中保持可追踪的部件级物理表示，并验证其质量预测和局部属性？

## 目标方法

1. 采集真实多视角、相机与尺度。按物体隔离训练、验证、测试；分割、材料、物理属性各有对应监督，缺失项不能当作真值。
2. 高精度 Mesh 入口。参考网格轨道用来隔离下游误差，重建轨道用来评价实际端到端效果。生成视角不可当成新真实证据。
3. 层级分割：物体、部件、局部区域。比较几何法、图像投影、部件特征以及我们的边界融合；连通性只是证据之一。
4. 统一表示：Part Token 负责身份和全局证据，Local Field 负责局部与内部空间变化，Connection Graph 负责接缝、接触、固定或活动连接关系。潜空间投影与显式空间映射分别定义和评价。
5. 根据多视角、几何、语义和材料数据推断联合构造与属性分布，允许壳体、骨架、填充与空腔多个假设。VLM输出需要监督、约束和校准，不能把置信度直接称为准确概率。
6. 在有效的体积域内积分质量、一阶与二阶质量矩，计算COM与完整惯量。体积修补、占用率、材料密度以及不确定性来源分别记录。E与nu需要有依据的预测/均匀化模型。
7. 根据边界不确定性和材料物理差异进行风险控制，分配视角、三角面和体素预算。实际迁移改变离散时比较边界和质量矩误差；复用固定体积状态产生的零漂移不是算法精度证据。
8. 使用独立标签、公平预算、多次重复、模块消融和失败案例评价。任何测试质量或其他测试真值均不得反馈到该物品的推断与细化。

## 候选贡献与证据

- A：边界感知的部件与局部物理信息融合。以参考部件、材料标注、边界指标和对照消融验证。
- B：物理风险驱动的细化与跨分辨率属性迁移。以相同预算下的几何、质量、COM、完整惯量误差和效率验证。
- 编辑与局部连接作为应用验证。连接强度只在结构、材料、载荷和支承已知时报告；几何距离不能当安全等级。

## 最终结果

- 属性图：真实图片、层级部件、材料、内部剖面、密度、E、nu、占用率、不确定性；区分实测、标注、预测与先验。
- 质量图和参数表：预测/真实对照、部件分解、ADE/ALDE/APE/MnRE、覆盖率与区间宽度。
- 几何和效率图表：固定面数/计算预算的边界、几何与物理误差曲线，耗时、显存与实验设置。
- 细节、连接和编辑：接缝、接触与连接近景，编辑前后构造和物理状态；数据足够时增加实测或力学仿真。
