# 问题、方法选择、优势与证据对应

日期：2026-11-04。本文配合[完整研究设计草案](research_blueprint_2026-11-04_zh.md)。
“推荐”表示适合当前任务、资源与监督条件的起点，不表示已经找到全局最优算法。
结构和程序性质、已执行解析检查、尚待模型实验的优势分别记录。原物体质量准确性仍
为首要目标，编辑后准确性为第二目标，效率在误差约束下评价。

## 1. 方法选择准则

1. 新增机制必须对应明确失败类型，并有独立参考和对照实验。
2. 尽量复用冻结前端，优先训练小型共享构造模块，不同时展开所有基础模型的微调。
3. 简单方法与复杂方法在相同输入、监督和成本条件下比较；增加模块没有收益就收缩。
4. 视觉无法辨识的问题保留歧义，缺少测量的属性不填写准确性结论。
5. 材料、内部构造、空间对应、接口和计算预算服务同一可执行部件状态。

## 2. 问题到方法的选择表

| 问题 | 推荐起点 | 解决机理与预期价值 | 成立条件与验收 |
| --- | --- | --- | --- |
| P01 绝对尺度不明 | 尺度来源审计，已知／估计尺度分轨 | 把尺寸错误与材料错误分开，防止立方量放大 | 有允许的尺度证据；无证据时输出尺度不确定性 |
| P02 初始Mesh缺件、粘连或破损 | 固定InstantMesh，原始／修复几何与参考几何诊断分开 | 定位重建瓶颈，避免用内部参数补偿错误外形 | 表面、轮廓、薄结构与失败清单；不以凸包冒充补全 |
| P03 分割粗糙，接口不清 | 初始部件特征加遮挡过滤、多视角边界和面图细化 | 保护可编辑部件身份及局部细节 | 部件IoU、边界、薄结构、接口定位分别评价 |
| P04 同材质部件误合并 | 分开部件实例、材料区域与接口图 | 四条同材质腿仍可单独编辑，一个坐垫可有多个材料域 | 有实例与材料两类参考；不把颜色变化都当接口 |
| P05 多视角冲突和遮挡投影错误 | 可见面索引／深度检查，聚合权重和覆盖记录 | 避免背景、背面及遮挡区域污染属性 | 同点对应误差、可见覆盖与视角消融；生成图非独立观测 |
| P06 表面材料不能代表内部 | 有限合法构造生成器，区分表皮、填充、框架与void | 建立可解释密度分布，并能对具体材料域编辑 | 已知构造或独立内部参考；候选遗漏不能静默实心化 |
| P07 VLM猜测和参数来源不清 | 冻结千问给候选，结构化单位／来源，学习模块再评分 | 限定候选空间，使判断可审计 | 候选覆盖率、独立标签和固定调用预算；自述概率不当后验 |
| P08 质量对而内部错 | 原质量加独立编辑响应监督，可辨识性与条件数审计 | 有条件地减少密度、占用、其余质量之间的补偿 | 编辑保持规定变量不变；同数据直接回归及体积监督对照 |
| P09 模态和离散域对不上 | 空间锚点先对齐，再融合特征；显式字段与latent共存 | 将同一部件、同一位置的信息关联 | 距离、法向、身份、可见性检查；重网格后检查错配 |
| P10 质量、COM、I互相矛盾 | 同一密度场积分原始质量矩，有限单元保留自身惯量 | 在所声明离散模型内保证计算来源一致 | 解析姿态／积分测试；一致性不等于真实属性正确 |
| P11 密度、E、摩擦、硬度缺少真值 | 密度和刚体质量分布为主，其他属性用独立子集 | 避免用材料猜测替代测量，保持可验证任务范围 | E与结构刚度分开，摩擦明确接触对，硬度明确量表 |
| P12 不确定性虚假自信 | 构造与参数联合不确定性，独立调参／校准，概率评分 | 对不可见内部保留多个解释，提供可检验区间 | 同材质和尺度保留相关性；覆盖与宽度一起报告 |
| P13 密集构建计算量大 | 先验证局部解码，再按接口及物理／编辑响应误差分配预算 | 把计算用于影响结果的薄结构和接口 | 与均匀、QEM、几何保护比较完整成本，检查粗细过渡 |
| P14 编辑只有外观变化 | 严格材料／构造／部件操作，直接修改共享物理状态 | 可输出实际占用、材料场和编辑后质量矩 | 独立编辑参考；材料改变不自动改空实心，颜色仅作预览 |
| P15 编辑后重复处理或旧证据覆盖 | 字段依赖和版本、局部更新、原始观测与编辑条件分开 | 复用真正不变的计算，保持状态可追溯 | 全局依赖需扩大更新；含检查成本的耗时及全量重算核对 |
| P16 内部／编辑标签不足 | 已知CAD配对与可测装配体，按对象和家族划分 | 为隐变量和编辑结果提供独立监督 | 不用预测状态自造真值；记录附加监督与标注成本 |
| P17 基线输入和监督不公平 | 单图、多视角、共享几何三轨；监督量分组 | 区分方法、输入及标签带来的收益 | 官方实现版本、实际运行、固定清单；文献分数另表 |
| P18 仿真漂亮却不能证明准确 | 已知力、力矩、平衡等受控响应，再做机器人演示 | 将参数误差联系到可测交互后果 | 独立参考、固定控制／接触条件；自由落体不验证质量 |

## 3. 共同机制及每部分的职责

图像和初始几何产生部件及构造证据，空间对应将其绑定到共享部件状态。学习模块输出
合法构造和材料参数，由同一物理算子计算原始与编辑后结果。训练用独立响应排除部分
错误解释，构建模块按同类物理任务的误差预算分配分辨率，编辑执行器更新受影响状态。

已有重建、分割、VLM、Huber／交叉熵和缓存作为基础工具。候选方法贡献在于共享构造、
有区分能力的独立编辑监督、可执行状态与任务预算之间的具体关系；需由消融证明。
统一数据结构或把loss改名本身不构成充分创新。

## 4. G0解析检查：一次编辑不总是足够

### 4.1 模型与适用条件

考虑单一均匀材料相加空腔的目标部件，其余装配质量为b：

```text
m0 = b + rho * f * V
m1 = b + rho1 * f * V
m2 = b + rho2 * f * V
```

V为已知外包络体积，0<f<=1，rho为未知密度，b为未知非负其余质量。
两次编辑的新密度rho1、rho2独立已知，目标几何、宏观占用和其余部件／附件保持不变。
这是解析参考模型，不是从RGB恢复真实物体的算法，也不是所有构造的辨识定理。

当b已知，原观测加一次有效编辑可约束rho和f；当b未知，通常有三个未知量，原观测加
一次编辑仍不足。两次互异密度编辑可在该模型下增加独立信息：

```text
V_material = (m2 - m1) / (rho2 - rho1)
b = m1 - rho1 * V_material
rho = (m0 - b) / V_material
f = V_material / V
```

若V未知，材料体积仍可由质量差约束，但填充率f与外包络体积仍有歧义。
若编辑同时改变附件或宏观占用，上述消元不再成立，需增加未知量和参考观测。

### 4.2 已执行结果

入口：`python scripts/audit_edit_observability.py`，只使用NumPy，不下载数据或运行GPU。
检查解析Jacobian与独立有限差分、可恢复参数、重复编辑负控制及接近重复的病态情况。
质量和参数均为指定合成设计，数值不是ABO预测成绩。

| 观测 | 未知量数 | Jacobian秩 | 能支持的结论 |
| --- | ---: | ---: | --- |
| 仅原质量 | 3 | 1 | 存在多种补偿解释 |
| 原质量加一次材料编辑 | 3 | 2 | 其余质量未知时仍不充分 |
| 原质量加两个互异密度编辑 | 3 | 3 | 在声明条件下局部满秩，可解析恢复 |
| 两次相同密度编辑 | 3 | 2 | 重复观测不等于新的独立约束 |
| 两次非常接近的密度编辑 | 3 | 3 | 满秩但可严重放大测量误差 |

所选归一化算例中，互异密度编辑条件数约13.86，接近重复编辑约7279.59。
条件数依赖参数归一化，不能脱离本模型比较任意系统。
在两个称量误差独立、标准差均假设为1g且密度和体积精确的示例下：

```text
sigma_f = sqrt(2) * sigma_mass / (abs(rho2-rho1) * V)
```

本例密度差1500kg/m3时sigma_f约0.000943；差1kg/m3时约1.414。
这是误差传播示例，不是实际测量精度，也未计入密度、制造、占用和尺寸的不确定性。
因此编辑设计应考虑测量噪声与可制造性，不能仅追求编辑数量。

示例中，两个不同状态能给出相同原质量0.65kg及第一次编辑质量1kg，而第二次编辑
分别为1.75kg和1.6kg。参考数值与代码输出见[审计JSON](results/observability_audit.json)
及[审计CSV](results/observability_audit.csv)。

### 4.3 对模型设计的影响

1. 训练配对优先选能区分当前候选的互补编辑，并审计敏感度和条件数。
2. 真值来自独立已知构造或测量，不来自模型预测内部生成的编辑重量。
3. 与同信息量的直接体积／占用监督比较，识别新增标签与方法本身的作用。
4. 部署时只看RGB并没有自动获得这些编辑观测；训练归纳规律不能消除测试输入的
   固有歧义。需要保留候选或增加另行声明的测量条件。

## 5. 优势应分成三个证据等级

### 5.1 可以由模型定义或软件检查建立的性质

- 同一物理场产生m、COM、I，避免自由预测分支之间无约束的矛盾。
- 部件与材料区域分别维护，能够表达一个部件内多材料及同材料多个部件。
- 类型、单位、版本和依赖明确，非法编辑能够拒绝并回滚。
- 对完全相同输入和依赖可复用缓存；给定合法状态可核对局部更新与完整重算。

这些性质具有工程价值，但不自动代表原创性、真实内部恢复或更高物理准确性。

### 5.2 必须用实验争取的优势

| 预期优势 | 为什么可能出现 | 必须检验的对照 |
| --- | --- | --- |
| 原物体质量更准确 | 构造监督与独立响应减少部分密度／占用补偿 | 同数据直接质量头、实心／薄壳、直接体积监督 |
| 编辑后物理更准确 | 原始与编辑结果受同一可执行构造约束 | 同配对数据独立分支、旧字段拼接、独立编辑参考 |
| 接口和薄结构更完整 | 分区与构建考虑编辑需要和材料支持 | 普通分割、几何保护、接口预测与给定接口诊断 |
| 计算预算更有效 | 平坦均匀区域减少查询，敏感区域保留分辨率 | 密集／均匀／QEM／任务预算，含全部预处理开销 |
| 更新更高效 | 复用未改变依赖，只重建受影响区域 | 全量重算，含映射、碰撞、接口和全局依赖成本 |
| 概率更可靠 | 独立校准与适用评分抑制无依据的高置信 | 覆盖与宽度、候选失败、域外与歧义负控制 |

### 5.3 目前不能宣称的优势

不宣称已比PUGS、PhysVGGT或Gen2Physics准确；不宣称一定更快；不宣称RGB能唯一恢复
隐藏结构；不宣称所有局部属性都有真值；不宣称接口几何合法即承载可靠。
不因使用Mesh、VLM或统一token就主张首次提出。主任务受监督训练时不能称零样本。

## 6. 针对最近工作的定位

PUGS已有几何和区域约束，Gen2Physics已有Mesh材料分解与内部构造推断；这些是必须
认真比较的近邻。PhysVGGT的独立全局质量分支可作为直接回归范式的强对照。
AdaVoMP已有自适应材料表示，PhysChoreo已有部件物理编辑；本研究需证明更具体的
构造监督、状态一致性与物理任务预算价值，不能以这些概念本身主张新颖性。

论文对比坚持同观察条件、尺度证据、训练信息与固定对象清单，按单图／多视角／共享
几何分轨。公开可运行资源尚未核验的方法列待复现，文献数字和实际重跑结果分开。

## 7. 按误差瓶颈选择下一步，而非不断加模块

在具有独立标签的子集上，依次替换正确尺度、几何／分割、材料及占用，观察剩余误差。
各因素有交互，改善量不能直接解释为可相加的独立误差贡献。没有某项真值时，不能用
VLM输出充当oracle。

| 诊断结果 | 优先处理 | 暂缓 |
| --- | --- | --- |
| 正确尺度后误差大幅下降 | 尺度证据与校准协议 | 增加内部候选和大模型微调 |
| 参考几何远好于生成几何 | 薄结构、对齐、重建失败及构建支持 | 强迫材料参数补偿几何 |
| 已知构造显著改善，材料仍错 | 候选覆盖、专业先验与小模块材料头 | 无边界的自由体素拟合 |
| 同质量内部错误，编辑响应可区分 | 独立配对、互补编辑及共享构造训练 | 仅增加总质量loss权重 |
| 已知内部仍无法稳定积分 | 几何域、计量、离散收敛和数值稳定 | 训练更大的模型 |
| 精度尚可但局部更新慢 | 测量依赖、映射、全局校验和缓存成本 | 预设局部操作恒为常数成本 |
| 自适应不能节省完整成本 | 收缩效率结论，保留固定前端做主任务 | 用后处理重命名生成加速 |

## 8. 实施优先级

P0：尺度与数据审计、已知构造／编辑配对、共享状态与质量矩。
P1：真实单物链路、固定十例错误分析、共享构造与直接回归／体积监督对照。
P2：精细接口、互补编辑、局部构建与多预算评价。
P3：概率校准、独立局部属性、真实机器人或变形任务，按核心结论所需逐项增加。

已有解析审计仅完成G0的一部分；复杂构造、图像到状态模型和训练梯度仍需验证。
本轮没有运行新大模型、服务器训练或真实物体实验。下一步按诊断证据选择实现内容，
每项“优势”在得到独立结果后才能改写成论文中的性能结论。
