# PartPhy3D：质量准确性与机械臂验证协议（设计稿）

日期：2026-10-30。本文定义待实现的研究与评价协议，不包含新的实验结果。对应总方案：`docs/ieee_trans_method_contributions_zh.md`。

## 1. 需要证明的四件事

1. 未编辑物体的独立物理预测：相同测试输入和数据预算下，不执行任何编辑，直接对比NeRF2Physics、PUGS、PhysVGGT等方法的质量与有参考依据的局部属性准确性。这是必须独立成立的主任务。
2. 编辑后：材料、内部结构和几何发生明确变化时，更新后的质量分布、接口与接触属性仍与独立参考相符。
3. 更新成本：增量方法在相同编辑状态下与全量计算一致，同时降低实际耗时；一致性与物理真值误差分别评价。
4. 操作作用：固定机械臂控制策略，改变属性输入后，抓取和搬运表现产生可重复、可归因的变化。

准确性、可编辑性、计算一致性和操作表现各有独立证据，不能相互替代。

主结果表首先报告原物体的首次预测，不以“编辑后更新正确”代替原始预测准确。目标是在统一协议下提高质量与局部属性预测性能；尚未取得可支持优于基线的实验结果。

## 2. 基准与公平性

### 2.1 质量主基准

ABO-500按官方物体ID划分，训练/验证/测试物体隔离，同物体全部视角属于同一划分。以官方ID清单为准，通常采用300/100/100协议；保存实际ID、文件哈希和排除原因。与官方测试集重叠的外部训练资产也需排除。近重复、同款变体和元数据潜在泄漏另行审计。

主对照为NeRF2Physics、PUGS、PhysVGGT；具备代码、权重和资源时补充VoMP、AdaVoMP与Gen2Physics。未复现方法不能写作本地实测结果。

PUGS原文质量表基于全500个对象。PhysVGGT表1标注100个测试对象，同时引用既有方法数字。因此不能直接将这些数字拼成我们的统一测试主表。对能运行的模型使用同一测试ID重新预测；原文引用单列“文献报告值”，标明协议。

设置两条几何轨道：

- 原始资产Mesh：诊断几何/构造与属性算法；保留正确物理尺度，不称为真实内部结构。
- InstantMesh重建Mesh：评价实际入口的端到端误差；标明尺度来自何种观测。使用真值尺度时，各可适用对照获得相同尺度信息。

至少报告两种输入预算：单张真实输入图像；固定数量的真实/原始渲染多视角。InstantMesh生成的视角属于算法内部计算，不算新增独立真实观测。方法能力不支持某一设置时标明适用范围。对比单图PhysVGGT和多视角方法时同时披露输入差异。

训练预算分开列出：限定ABO-500训练划分的对照；使用额外数据或公开预训练权重的对照。披露物体数、外部监督、VLM版本、是否微调、每物体推断时间及所需硬件，不把不同训练数据下的差异全部归因于方法。

### 2.2 局部属性基准

ABO产品质量只能监督总质量，不提供完整局部物理真值。使用公开实测基准及自建独立测量补充局部评价，保留坐标/表面对应。

| 量 | 参考获取方式 | 主要误差 | 必须说明 |
| --- | --- | --- | --- |
| 质量m | 审计后的产品质量；实物电子秤 | ADE、ALDE、APE、MnRE | 物品/包装、单位、附件与装配状态 |
| 质心c | 已知组件质量与几何；独立多姿态称重/力矩测量 | 欧氏误差mm及按尺寸归一化误差 | 坐标系、夹具与传感器零偏 |
| 惯量I | 已知CAD/组件积分；合适的摆动辨识 | 完整张量相对Frobenius误差、主惯量误差 | 统一坐标、参考点、姿态及辨识误差 |
| 密度rho | 材料样本质量/可测体积，或已知构造数据 | MAE、相对或对数误差 | 表观/本征密度，空腔定义 |
| 摩擦mu | 指定夹爪材料、载荷与表面状态下的滑移/摩擦实验 | MAE、相对误差及任务相关分位误差 | 静/动摩擦、材料对、湿度/速度条件 |
| 接触刚度K或E | 固定压头、速度、区域的力—位移测量；E需适用本构反演 | 力—位移曲线误差，K或log(E)误差 | 壳厚、支承、载荷范围；K与E不能直接等同 |
| 硬度H | 对应标准、量程的硬度计测量 | 对应标尺MAE | Shore A/D等标尺分别评价 |
| 内部/壁厚/占用 | 已知构造CAD、程序化数据、可拆解实物 | 占用IoU、壁厚MAE、组分体积分数误差 | 合成、实测、VLM伪标签来源分开 |

COM和惯量没有可靠实测参考时，只在已知构造轨道评价，不以仿真参数自证实物准确。伪标签拟合度与实测属性误差分栏报告。木材方向性、软泡沫非线性与接触迟滞等第一版未建模条件进入限制说明。

局部属性的可执行评价接口、单位、样本对应规则和当前待测模板见`docs/local_property_evaluation_zh.md`。未编辑预测与编辑后预测均适用，二者结果分开报告。与NeRF2Physics硬度表直接比较时需复现其A/D拼接编码，单列为该基准协议；新增实物测量仍分别报告原生Shore A/D读数。

### 2.3 质量指标

对N个物体，m_j>0为参考、hat(m_j)>0为预测：

```text
ADE  = mean |hat(m_j) - m_j|                    单位kg，越低越好
ALDE = mean |ln hat(m_j) - ln m_j|              越低越好
APE  = mean |hat(m_j) - m_j| / m_j              越低越好，百分数需乘100
MnRE = mean min(hat(m_j)/m_j, m_j/hat(m_j))      越高越好，最大1
```

均值按物体计算，不按视角计算。零/负数、NaN与缺失输出作为失败记录，报告有效样本数和失败率；不得悄悄删除或用测试真值修补。对每个基线保留逐物体预测，使相同物体配对比较可追溯。

预先指定MnRE为质量主指标，同时完整报告ADE、ALDE、APE。研发目标为四项整体改善；论文按照实际结果说明在哪些指标、类别和结构上优于或弱于对照。不能在看完测试结果后才更换主指标，也不预填未经实验支持的性能数字。

同时报告类别、质量区间、薄壁/空心/复合结构的分层误差，避免大物体的kg误差掩盖小物体的相对误差。按物体做配对bootstrap置信区间，并披露随机种子、重复训练及推断变异。

90%预测区间另报覆盖率与宽度，有完整预测分布时可报CRPS等适用评分；校准只使用验证集。接近90%的覆盖率配合无限宽区间没有实际意义，需同时评价区间宽度和点预测误差。

## 3. 学习与一致性实验

主方案用局部构造/材料占用/密度得到可编辑质量分布，再进行积分。增加训练时的全局质量头与积分一致性研究，预先固定资产输出路径。所有监督只来自训练集，测试真实质量不参与密度、占用或候选选择。

必须有的同预算对照：

1. VLM材料先验＋固定实心比例。
2. 全局质量回归，不预测可积分内部字段。
3. 局部密度/占用积分，不使用全局质量头。
4. 两个输出头联合训练，关闭一致性约束。
5. 构造感知联合训练，启用明确权重的一致性约束。
6. 去掉真实尺度、跨视角对应、内部构造或局部监督的消融。

单列全局头、积分输出和校准区间；禁止用测试真值缩放后作为视觉预测成绩。总质量正确仍可能是错误密度与错误体积相互抵消，因此局部属性和已知构造参考必须独立评价。

若引入主动接触，必须另列视觉零接触、固定预算接触和有实测属性参考组。触觉或力/力矩读数是新增证据，选择接触位置的收益须在相同探测次数、时间和传感器条件下验证；不将这一待选模块计作已完成贡献。

## 4. 机械臂实验

### 4.1 设备与任务条件

实施前登记机械臂、夹爪材料与几何、可用力/力矩或指端传感器、控制频率、相机与尺度标定、工具质量和夹具坐标。先在设备允许范围内做低复杂度可重复试验，再扩展物体类别。本文未指定任何硬件执行命令。

对象覆盖刚性/柔性、表面高/低摩擦、相近外观但内部或质量分布不同的情况。使用独立实物；无需假设能购买到ABO中的同一商品。若外观/构造与训练资产同款，单独标记，不作为完全独立泛化证据。

至少包含：稳定提起并保持；固定轨迹搬运与放置；有可测变形阈值的软物体抓取；可重复更换材料、部件或填充的编辑前后配对任务。编辑后重新测量质量、COM和接触响应，不能直接沿用编辑前真值。

### 4.2 控制变量与对照

相同物体、抓取候选、接触区域、轨迹及控制律下，替换属性输入：

| 组别 | 控制器获得的物理信息 | 用途 |
| --- | --- | --- |
| 统一属性组 | 验证集确定的固定质量/摩擦/刚度 | 检验是否需要物体特定预测 |
| 各论文预测组 | 可复现的质量与局部属性；缺项用相同默认值 | 统一下游条件下比较预测作用 |
| 我们完整组 | 质量、COM、接触属性、适用的不确定性 | 端到端作用 |
| 我们消融组 | 去COM、去局部属性、去不确定性或去构造 | 识别具体信息贡献 |
| 实测属性参考组 | 独立测量的相应属性 | 测量属性输入下的参考表现，不称理论上限 |

只评价力控制作用时固定接触位置；评价属性辅助抓取点选择时另设实验并保持候选集合一致。不能同时换预测器、规划器和控制器后，把全部收益归因于物理估计。

对理想对称双指静态抓取，单指法向力N的简化抗滑条件为2*mu*N >= m*g；实际加速度、COM偏移、接触姿态和柔性会改变要求。此式由各接触的库仑摩擦界与静力平衡得到，相关模型见[Modern Robotics第12.2.1节](https://modernrobotics.northwestern.edu/nu-gm-book-resource/12-2-1-friction/)。它仅说明质量与材料对摩擦共同影响抓取力，不是本项目真实机械臂控制器或安全保证。E/硬度也不能单独决定夹爪开度。

纯视觉组输入预测分布；若控制器按保守分位数设置力，应报告较高夹紧力引起的变形/损伤代价。接触辅助组在相同观测预算下独立评价，不把称重之后的质量成绩写成视觉估计成绩。

### 4.3 评价和统计

- 预先定义提起高度、保持时间、搬运轨迹、允许滑移和成功条件；数值由设备和物体范围确定。
- 主报成功率、滑移/掉落率；有测量条件时报告峰值/持续接触力、形变/损伤、放置误差、任务时间。
- 报告主动拒绝、转交和重试；“只对容易物体执行”需同时报告任务覆盖率，不能仅给已执行任务成功率。
- 试验顺序随机化，记录表面磨损与物体状态；重复次数依据先导方差与预期可检测效应确定。物体是泛化统计单位，重复抓取是物体内重复，不能视作同等数量的独立对象。
- 分别展示属性误差与任务表现。二者的相关性可作为描述；通过属性替换/消融建立更可信的归因。

## 6. 文献事实与创新边界

- NeRF2Physics提供质量指标和真实场景局部属性评价起点：[CVPR 2024原文](https://openaccess.thecvf.com/content/CVPR2024/papers/Zhai_Physical_Property_Understanding_from_Language-Embedded_Feature_Fields_CVPR_2024_paper.pdf)。
- PUGS报告全500对象质量，并已有利用预测属性的抓取应用：[原文第IV节](https://arxiv.org/html/2502.12231v2)。
- PhysVGGT将全局质量与局部密集属性分别预测，并比较直接质量头与密度体积路径：[原文及附录](https://arxiv.org/html/2609.18920v1)。物品质量标注与自动生成的局部属性伪标签需区别。

质量预测、抓取演示、概率分布和全局头各自都已有相关工作。拟议贡献需要由“构造感知的可编辑物理字段＋接口约束协同编辑＋依赖增量更新”的具体机制支持，并同时给出独立物理准确性及机械臂收益证据。本文没有证明优于已有论文，也没有实施机械臂实验。
