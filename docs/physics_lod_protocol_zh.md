## 1. 目标与技术范围

目标是在物理估计和编辑所需精度下减少表面三角形数量。平坦同材质区域允许更多边折叠；薄壁、材料边界、部件接口及接触候选区保留较高几何分辨率。大三角形应来自可控重三角化或边折叠，不是把轮廓向外扩大，否则会改变体积和质量。

QEM是已有基础算法，必须引用：Garland与Heckbert，[Surface Simplification Using Quadric Error Metrics](https://www.mgarland.org/research/quadrics.html)。已有自适应物理场工作，例如[AdaVoMP](https://research.nvidia.com/labs/sil/projects/adavomp/)，因此“自适应”“减少计算”本身不能作为首创主张；表面网格简化与内部体积场自适应也不能混称同一种方法。

## 2. 已有代码与实际运行边界

`src/tactile3d/mesh/physics_lod.py`实现：

1. 以普通QEM生成若干目标面数的候选。
2. 检查相对体积、包围盒尺度归一化的质心位移、惯量范数差和表面积差。
3. 选择满足阈值且面数最少的候选；无候选通过时保留原网格。

默认阈值分别为4%、0.75%、5%、1%。这些是当前配置，不是经独立物理实验确认的安全界限。当前惯量检查比较张量范数，不能保证主轴方向或完整张量一致。体积/质量代理建立在几何和均匀单位密度假设上；非水密网格的有符号四面体结果只是跨分辨率代理，不是真实封闭体积。

`src/tactile3d/experiments/ten_objects.py`中的10物体流程并未调用上述筛选器，而是在原物理场计算完成后运行普通QEM，导出约50%和25%面数的诊断结果，并以最近原三角形中心转移显示标签。它没有局部边界锁定，也没有独立重算减面几何下的物理字段。

例：躺椅`B07B4G5RBN_ATVPDKIKX0DER`从9490面减至2371面，表面积变化约19.14%。诊断CSV中的质量完全相同，源于复用原字段，不是独立验证减面无误差。该记录保留为失败风险示例。

## 3. 拟实现的任务相关改进

以下是下一阶段设计，不是已完成算法：

- 在初始部件/材料划分后，构建局部保护区，优先锁定接口、薄结构、可靠材料边界，并检查折叠后的翻面、退化、拓扑及边界偏移。
- 低置信边界单独标记，比较保护与不保护的影响；不能把所有初始分割错误都固定成不可修改边界。
- 对允许折叠的候选使用几何误差和局部物理敏感度选择顺序，检查候选导致的质量分布变化。具体评分及近似开销需要实现和消融，不能只给一个加权和就认定创新。
- 简化表面继续绑定稳定部件ID与原物理域，维持可追溯的空间映射；显示标签的最近中心映射不自动等于可靠的物理字段迁移。
- 在候选筛选时控制质量、质心、完整惯量张量、接口位置与几何误差。以原分辨率预测字段为参考时，只能证明近似误差受控，不能证明对真实物体准确。

可将目标表述为：在上述误差预算内最小化表面面数。若不满足预算，则提高局部分辨率或退回原网格。预算在训练/验证或明确设计需求中确定，不能按测试物体真实质量挑选减面结果。

## 4. 计算收益必须定位到具体阶段

面数减少可能降低表面属性投影、三角形查询、部分碰撞与编辑操作的成本，实际收益依赖实现。不能推导为VLM推理、固定图像分辨率渲染、固定粒子数MPM或固定体素数积分必然同比加速。

区分两个轨道：

- **表面/显示轨道**：复用高分辨率物理域，只减少显示、查询或编辑几何。报告这些阶段收益；不宣称减少了原构造推断或体积积分开销。
- **下游重算轨道**：真正将减面结果用于投影、场构建或后续操作，重新计算物理量。报告近似误差、真实准确性及端到端耗时。

加速模块应放在可实际影响相应算子的阶段。当前先求物理场再减面的运行不能用来证明初次物理推断更快。内部体素或MPM粒子预算若要减少，需要额外离散策略和独立验证；不为本轮强行扩展范围。

## 5. 最小效率实验

固定10物体、硬件、输入分辨率、随机种子及下游任务。保留所有失败，不以视觉效果选择对象。

对照：原网格、普通QEM、几何/边界保护简化、拟议物理与接口约束简化。后两者在实现后才填写结果，不伪造已运行成绩。

采用两种比较：相同面数下比较误差，相同误差预算下比较计算开销。

记录：

| 项目 | 指标 |
| --- | --- |
| 几何压缩 | 原面数、实际面数、减面比例、双向表面距离、法向误差 |
| 部件与接口 | 部件/材料边界误差、接口位置/方向误差、薄结构保留与失败率 |
| 物理近似 | 相对质量漂移、归一化COM位移、完整惯量张量相对差 |
| 真实准确性 | 独立质量标签下ADE/ALDE/APE/MnRE；其他真值可用时追加 |
| 计算 | 简化与映射预处理、投影/查询、场构建/积分、编辑、交互仿真各阶段及总耗时；CPU内存和适用的GPU峰值显存 |

不得用惯量范数的标量差代替完整张量差。质量和惯量接近零时预先定义可解释的归一化与缺失处理，不用任意小数掩盖退化情况。

报告冷启动总成本`T_preprocess + T_operation`，以及复用N次的摊销总成本`T_preprocess + N*T_operation`，同时给出原网格对应成本；N在协议中确定。不仅报告最有利单阶段，也不把面数减少75%写成总耗时减少75%。

建议一张四栏图：原网格、普通QEM、拟议方法、接口/薄壁放大；加一张速度—误差曲线和一张阶段耗时表。当前没有对应性能结果，不预填加速倍数。

## 6. 可用于论文的方法草稿

> 为降低部件物理处理与编辑的几何开销，我们研究任务约束下的网格简化。方法利用部件、材料边界及接口信息分配表面分辨率，在低风险区域执行简化，并检查物理质量矩及接口偏移，以选择满足误差预算的几何表示。简化表示通过稳定部件身份与空间映射关联原物理状态。效率实验分别统计预处理、下游操作及重复编辑成本，同时评价对独立物理准确性的影响。

该段描述目标方法。投稿时必须按实际完成算法修订；当前能直接描述的实现仅为QEM候选生成和全局物理代理筛选。

## 7. 稀疏化命名与消融（2026-11-02补充）

用户提出将减面表述为稀疏化，并比较无稀疏与有稀疏的差距。当前明确为**物理与接口约束的自适应表面网格稀疏化**，指减少表面顶点/三角形并在任务敏感区域保留分辨率；不指稀疏注意力、稀疏网络或已实现内部体积场稀疏化。它仍属于网格简化，命名变化本身不增加原创性。

定义三角形稀疏率`s_F = 1 - F_reduced/F_original`，另报顶点数与顶点稀疏率。示例：保留25%面数对应约75%三角形稀疏率；不等同于体积占用率、显存节省率或总计算量下降率。空间粗细分配由具体实现与保护区决定，不由全局稀疏率自动保证。

核心三组：

| 组别 | 设置 | 目的 |
| --- | --- | --- |
| 无稀疏 | 原网格、相同下游流程 | 计算与精度参考 |
| 普通简化 | 普通QEM、匹配实际面数预算 | 区分一般减少面数带来的收益 |
| 任务约束稀疏化 | 局部接口/材料边界/薄壁保护及物理误差控制 | 检查新增策略的作用，未实现前不填写性能结果 |

已有全局物理代理筛选可以作为额外消融，以区分候选后筛选和局部保护。无稀疏/有稀疏两组可以作为展示摘要，完整评价保留普通QEM组。

候选面数保留率100%、50%、25%、10%是拟议预算扫描，不是保证全部可行的目标。100%作为原网格点，其余记录实际保留率、约束是否通过与回退状态；不能把回退原网格画成满足原定稀疏率。

实验运行相同下游操作，报告预处理及总耗时、CPU内存/适用GPU显存、独立质量误差、相对原网格的质量/COM/完整惯量差、边界与接口偏移及失败率。原始真值缺失的指标标明缺失，原预测只作为数值近似参考。至少同时给出匹配面数和匹配误差预算的比较。

拟输出：

1. 原网格、普通QEM、任务约束稀疏化的相同视角图，附连接、薄壁与材料边界放大。
2. 稀疏率—总耗时和稀疏率—物理/接口误差曲线，所有方法使用相同尺度；另给速度—误差前沿。
3. 10物体逐对象配对结果与汇总表，保留失败及几何复杂度差异，不仅展示最好对象。

若简化仅在原物理场计算后用于显示，则只能评价显示/查询等受影响操作及几何误差。原字段复用得到零质量变化不是独立物理精度证据，也不能证明初次物理推断加速。
