## 2. 保留的方法与收敛后的论文范围

主线：**面向部件编辑的构造感知物理估计——准确估计原物体，并在部件替换后准确更新物理状态。**

原物体准确性和部件可编辑性是共同目标，不能用编辑速度替代原物体物理准确性，也不能在讨论中遗失部件编辑。

```text
ABO-500图像、相机及尺度
  → InstantMesh固定权重生成初始Mesh（端到端轨道，尚未跑通）
    / 官方参考Mesh（物理模块诊断轨道）
  → 多视角对应、初始部件与材料区域
  → 千问提供表面材料、隐藏构造与连接候选
  → 我们研究的部件构造推断：材料、壁厚/占用、密度及不确定性
  → 同一部件状态与空间字段计算原物体质量、质心、惯量
  → 接口兼容的部件替换，同步材料、构造与物理状态
  → 编辑后物理量及独立评价
```

- InstantMesh、PartField等初始分割模型和千问作基础工具，不自动构成贡献。参考Mesh和生成Mesh分轨报告，输入优势须披露。自研图像重建暂作备选扩展。
- 统一部件状态保留视觉、语义、几何、构造、材料、物理属性及稳定空间对应。字段拼接、统一维度本身不证明有效对齐或原创性。
- 第一版重点是质量准确性；密度、壁厚、占用为解释变量。无对应真值时，不把这些变量宣称为准确恢复。
- 第一版编辑限定于接口兼容的部件替换，可覆盖明确指定的材料和内部构造变化；复杂自由几何生成与连接力学适配后续扩展。
- 杨氏模量、摩擦、硬度及其属性图保留为完整研究方向，只有有可信标签和适用协议的属性才做准确性主张；可视化不代替真值验证。
- 减面、统一映射和缓存先作为支撑实现。平坦同材质区域可粗化，薄壁、材料边界、连接处保留细节。当前QEM加物理代理筛选不等于已实现局部风险约束减面。
- QLoRA微调保留为后续实验选项，先验证固定模型与小型预测模块，不把微调本身列为创新。心理物理/触觉标注和机械臂验证保留为后续扩展，不混入首轮软件跑通验收。

两项候选贡献是：构造感知物理估计、共享部件状态下的编辑更新。它们均需要具体算法、充分查新与消融证据；本文件不确认其原创性。

补充约定：将减面作为方法中的效率模块，并加入精度—成本实验，不从方案中遗失。具体已有实现、拟议局部保护和验证协议见 [物理与接口约束网格简化](physics_lod_protocol_zh.md)。是否提升为独立贡献取决于算法差异和实验证据；当前尚未证明端到端加速。

稀疏化补充：将该模块具体定义为自适应表面网格稀疏化，后续比较无稀疏、普通QEM、任务约束稀疏化；记录稀疏率与精度—成本曲线。不把表面减面自动解释为内部体素、MPM粒子或网络计算的稀疏化，详见上述协议第7节。

- 单物体专用规则获得的接近质量标签结果，不能替代上述通用10物体成绩。

## 4. 执行顺序：先10物体，再完整数据集

1. 验证服务器连接、GPU、环境、数据及模型权重路径。认证信息不写入项目记录。
2. 从已固定的10物体中用一个对象进行真实模型冒烟检查，再处理同一固定10物体清单，不按误差替换对象。
3. 跑通真实模型路径，保存每模块来源、版本、配置和日志。模型失败明确记录；不得静默回退规则后仍称真实模型成功。
4. 检查几何尺度、多视角投影、分割边界、内部占用、质量积分和接口兼容的部件替换；输出原物体与编辑后图片和数值。
5. 冻结有效配置并完成训练/验证选择后，扩展至完整数据集推理与正式评测。

“完整数据集运行”不等于使用全500物体质量训练后再在同一集合声称泛化。遵守官方训练/验证/测试划分；当前10物体已被查看和用于开发，不能再称未见的独立测试集。最终评测须披露开发暴露、使用未参与开发的留出对象，且不得把测试质量用于推断、调参或选择内部构造。

## 5. 十物体验收

功能验收与科学结论分别记录：

- **可复现性**：固定清单、配置、随机种子和模型版本；成功、失败、耗时、GPU显存及输入输出来源逐对象保留。
- **几何与部件**：尺度与相机对应合理，人工抽检薄结构、边界和连接；参考不足时不宣称精细分割已获定量验证。
- **体积与物理量**：单位一致，无材料重叠重复计量，质量/COM/惯量有限且符合解析检查；开放表面片不直接冒充独立封闭部件。
- **编辑**：接口兼容替换可执行，新增部件构造与质量同步；同条件完整重算提供数值对照。更新一致性不代替实物准确性。
- **图与表**：原图、部件、构造剖面、可支持的属性图、原物体质量表、编辑前后表、失败案例。未知属性标签保留缺失，不以预测或查表值充当实测。
- **准确性**：质量报告ADE/ALDE/APE/MnRE，并保留简单基线。10例只用于调试和发现失败模式，不据此认定统计优势或论文水平。

不因图好看、单例接近标签或积分自洽就进入性能结论。显著错误先定位来源，再判断是否值得扩展计算。

## 6. 最小论文证据链与边界

三个核心实验：原物体质量对比、可核验的部件替换、关键机制消融。对比保持输入/训练预算可解释；原文平均分不冒充同对象复现。

配对编辑监督是候选设计，需要已知构造的合成数据或独立实测的可拆装实物支持；ABO-500整物体质量标签不足以验证真实内部、每部件密度与编辑真值。

仅有外观不能确定唯一内部，材料密度与实心程度可能混淆；总质量正确不能证明局部属性正确。VLM自述概率与先验采样区间未必校准；泡沫表观密度与宏观空腔占用避免重复折减。

后续继续本项目时，先核对本文、10物体实验报告和实际运行日志，再更新方法与完成状态。需要更改主线时记录原因和新证据，避免无说明地漂移。
