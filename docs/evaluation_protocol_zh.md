# PartPhy3D 论文评测协议

> 2026-11-03更新：主表推荐使用固定清单注册表入口`python scripts/compare_experiments.py`，详见 [已实现对比流程](comparison_implementation_2026-11-03_zh.md)。以下旧交集模式不能代替完整失败报告；当前10例是开发集，分位数未必为已校准后验。

## 1. 评测对象

主任务是在预先固定的ABO-500队列上预测质量。注册表入口保持固定队列分母，缺失方法标记不完整，不计算其主表成绩；未运行方法不填数值。`paper-figures`命令现在必须提供`--cohort`，缺失物体时拒绝输出排名，报告同时保存对象清单和输入哈希。Python接口的交集模式仅供明确标注的探索分析。校准器和超参数只能使用训练/验证数据，正式测试质量只用于最终评价。完整比较约定见`configs/mass_comparison_protocol.json`。

## 2. 论文主指标

设真实质量为 `m_i > 0`，点预测为 `p_i > 0`，测试物体数为 `N`：

```text
ADE  = mean(|p_i - m_i|)                         [kg, 越低越好]
ALDE = mean(|log(p_i) - log(m_i)|)               [无量纲, 越低越好]
APE  = mean(|p_i - m_i| / m_i)                   [无量纲, 越低越好]
MnRE = mean(min(p_i / m_i, m_i / p_i))           [0-1, 越高越好]
```

这四项与 PUGS 发布的 `evaluation.py` 定义一致。PUGS 的输出若为 `[low, high]`，其点预测
按相应实现取 `(low + high) / 2`；这些范围不自动是q05/q95，也不是中位数。PartPhy3D点预测规则必须声明，当前规则实验使用先验采样均值。原始误差JSON/逐物体CSV的`ape`保留比例，新主表CSV的`ape_percent`和图显示百分数。

ADE 对重物体更敏感；ALDE、APE 和 MnRE 更关注相对误差。不能只挑一项最优指标报告。
建议正文同时给出四项均值和 95% 置信区间，并在补充材料报告 RMSE。

## 3. 概率预测

若模型报告q05/q95，可评价名义中央90%分位区间的命中率与宽度；只有有对应推断与校准证据时才能称已校准后验。当前开发规则的先验分位区间只作描述性诊断：

```text
Coverage90 = mean(q05_i <= m_i <= q95_i)         [越接近 0.90 越好]
NormWidth90 = mean((q95_i - q05_i) / m_i)        [在覆盖充分时越低越好]
```

覆盖率不能简单解释为越高越好：100% 覆盖但区间极宽没有实用价值。因此必须把覆盖率和
归一化宽度一起报告。若覆盖率显著低于 0.90，说明模型过度自信；可仅在验证集上使用
conformal calibration 或温度/尺度校准，再锁定参数评测测试集。

## 4. 统计与作图

- 所有误差均先逐物体计算，再对物体求宏平均。
- 95% 置信区间使用成对非参数 percentile bootstrap，默认 2,000 次、固定随机种子 17。
- 方法间差异应补充同一 bootstrap 重采样下的 paired difference，而不是比较两个独立区间。
- 主图输出 SVG/PDF（可编辑）与 600 dpi PNG/TIFF，并同时保存 `comparison_source_data.csv`。
- `predicted_vs_ground_truth` 使用相同横纵范围和对数坐标，虚线表示理想预测 `y=x`。
- 任何示例、smoke test 或人工构造结果必须标注为演示，不得作为论文实验数值。

## 5. 建议论文表格

主表：`Method | Representation | ADE↓ | ALDE↓ | APE↓ | MnRE↑`。

校准表：`Method | Coverage90 (target 0.90) | Normalized width↓`。

消融表至少包括：实心假设、仅表面材料、VLM 内部先验、体素部件体积、质量校准、完整模型。
每个表均保持同一固定样本数 `N`；缺失对象的方法不输出主表排名。失败与非水密 mesh 的逐项诊断保留内部日志，本轮不制作论文失败统计图。

## 6. 结论边界

ABO-500 只有物体级质量真值。部件密度、杨氏模量和内部结构图是模型推断，不是该数据集
提供的测量真值。若要声称部件级触觉参数准确，必须增加带材料测试、称重或力-位移测量的
独立数据集，并分别报告材料分类、密度误差、模量对数误差和部件质量误差。
