# 租用服务器的执行次序

当前研究仍以五物体开发先导为范围；真实模型与参考Mesh诊断分轨。
已有CPU测试通过不代表GPU链路已经运行。五个测试物体不用于凑大模型微调集。

## 1. 连接和运行环境

先保留主机密钥校验，使用本机授权密钥登录新租实例。只读检查GPU型号、驱动、
Python、依赖、磁盘及已有权重。复用已兼容的下载缓存，项目放在数据盘独立目录。
SSH密钥、密码、实例地址不放进公开仓库或实验包。

## 2. 软件和数据验收

安装统一requirements；核对CUDA版torch及实际训练API导入。
验证五物体、150图和相机、参考GLB的哈希，再运行必要单元测试。
闭合Mesh积分、已知构造换材是软件验收；它们不算ABO真实预测结果。

## 3. 首物体真实模型链路

固定队列首物体为`B07B4G5RBN_ATVPDKIKX0DER`。
先冻结观测视角、模型版本、权重和提示，执行一次真实重建和材料候选推断。
生成Mesh与参考GLB保留独立来源；不在失败时以参考几何替换生成结果。
记录尺度来源及相机配准，不读取真实质量反推尺度、密度或填充。

依次检查：重建质量、跨视角部件对应、可闭合材料域、候选结构和推断耗时。
遇到几何或模型失败先保存日志并修复，避免把同一错误扩散到全部物体。
图像外表不能唯一确定内部时，保留候选和未知项，不把模型自述当测量真值。

## 4. 五物体开发实验

首例通过后处理冻结五物体，失败不换样本。保存预测后再接入称重标签评价。
区分参考Mesh输入轨与图像生成Mesh输入轨。
先评价质量ADE、ALDE、APE、MnRE及区间覆盖率与宽度。
密度、杨氏模量、摩擦的准确性必须有对应独立参考；ABO总质量不能代替这些标签。

## 5. 方法和编辑消融

在相同输入下比较表面实心假设、结构候选，以及我们实际实现的联合机制。
几何误差与内部参数错误分开审计，不能通过试验集调参弥补形状错误。
材料编辑比较局部更新与完整重算；已知设计评价质量、质心及完整惯量。
真实编辑精度须有独立编辑后称重或构造参考，颜色改变不构成物理正确性证据。

## 6. 自适应预算和外部对照

与均匀预算、几何预算做等开销或等误差比较，保留不利结果。
分开记录前端、表面构建、物理处理、编辑的时间和峰值显存。
仅后处理减面时，不能把收益算作InstantMesh首次推理提速。
NeRF2Physics、PUGS、PhysVGGT只有真实执行、输入条件可比时才能填写主表。

## 7. 停止扩大无效计算的条件

先导没有可核验的部件、尺度和材料域时，不扩大为整套数据集或长时间QLoRA。
微调需要对象隔离的可信训练/验证样本及基座模型对照，先通过错误分析确认必要性。
所有结果记录成功、失败、耗时、配置与文件哈希；图片、表格只读取真实产物。
