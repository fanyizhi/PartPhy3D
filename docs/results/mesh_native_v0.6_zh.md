# v0.6.0实际执行结果

2026-11-05，本机Windows/Python 3.13.0，CPU执行。默认384个独立解析合成对象，
246训练、66校准、72测试，按64个物体族划分。使用相同数据划分、350轮、
32隐藏单元，初始化种子17/29/43；初始化波动不是跨数据集置信区间。

## 软件和指定构造核对

- 本地完整测试：157通过，14.25秒；Ruff及新增模块Black/88列检查通过。
- 三类构造核对和一次外壳换材：解析质量误差至多7.2×10⁻¹⁵kg；
  中心惯量误差至多9×10⁻¹⁶kg·m²，属于浮点数值核对。
- 默认外壳与填充均为显式指定：9.7728→25.1136kg。
- 缓存更新与全量三角边界积分一致；三个视角的非目标变化像素均为0。
- 禁用体素入口后新演示和学习仍运行。原体素原型仍保留，不混同两条路径。
- 新主线完整CPU诊断耗时约12.8秒，仅描述该本机小实验，不能外推到ABO或GPU模型。

## 合成学习结果

下表为三种初始化的指标算术均值。ADE单位kg，ALDE使用自然对数，均越小越好。

| 条件 | 模型 | ADE | ALDE |
| --- | --- | ---: | ---: |
| 原物体 | 质量监督 | 0.429716 | 0.420387 |
| 原物体 | 共享状态＋编辑响应 | 0.361501 | 0.396735 |
| 原物体 | 直接响应回归 | 0.378517 | 0.440504 |
| 已见材料编辑 | 质量监督 | 0.506245 | 0.465599 |
| 已见材料编辑 | 共享状态＋编辑响应 | 0.421389 | 0.393749 |
| 已见材料编辑 | 直接响应回归 | 0.447200 | 0.442680 |
| 未见钢材编辑 | 质量监督 | 2.325916 | 0.549318 |
| 未见钢材编辑 | 共享状态＋编辑响应 | 1.992266 | 0.437824 |
| 未见钢材编辑 | 直接响应回归 | 2.585360 | 0.732363 |

不应只挑有利指标：未见钢材编辑的APE从质量监督的0.580951变为
共享状态的0.618978，反而更差。误差与区间仍大，不能据此证明真实内部被识别。
原物体MAP资产的ADE分别为0.419310和0.394167，不等于混合预测的ADE。
