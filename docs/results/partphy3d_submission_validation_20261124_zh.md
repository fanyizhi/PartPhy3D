# PartPhy3D 投稿前的验证设计与实验记录

目标为 2026 年 12 月底前形成可提交的 IEEE Transactions 稿件。当前叙事围绕一个可测的技术问题组织。**图像支持的部件标签，如何约束同一物理域中的表面、内部材料和粒子，并在局部编辑后产生可验证的质量矩与运动响应。** 已有证据涉及几何诊断、局部编辑数值一致性和仿真演示。独立的物理真值决定各项精度结论能写到哪一步。

## 本轮问题、处理和结果

| 发现的问题 | 本轮修改 | 结果与下一项验证 |
|---|---|---|
| 原始货架漏细杆，旧方法膨胀轮廓又把杆间间隙填进模型 | 同一批六相机，在三维格点取各投影位置的连续有符号距离最小值，提取零等值面。保持既有 `0.80` 输入轮廓 IoU 门控。 | ABO-50 留出均值 IoU 0.9178 → 0.9220。货架 0.486 → 0.679。建立物理体积前还需以实测杆径或有真值网格验证。 |
| 密度覆盖指标未惩罚背景误填 | 固定同一材料证据，单列覆盖、精度与 IoU。完整有色轮廓显示虚假的物性区域。 | 五个共同留出视角上，旧补全与新补全覆盖率分别为 99.39% 和 97.46%，精度分别为 62.92% 和 79.29%。 |
| 低覆盖与材料误分混在一起 | 参考网格、重建网格各测一遍，冻结类别和相机。分别报告几何覆盖、表面有值比例、材质 IoU。 | 两件椅子的既有 PhysSeg 审核中，木材 IoU 为 32.71%，纺织物为 95.55%。先处理蓝椅腿的材质与边界，不用全局标签填满不确定表面。 |
| 图例无法对应具体物品与部件 | 用英文物品名标明每行，用真实的 ABO 重建视图和可见面 ID 对齐列，统一色标 | 产出三件同场景密度图、分部件物性图和前后换材图。 |
| 局部换材只看颜色会漏掉动力学后果 | 对真实参考躺椅固定网格与内部占用，在 3 组封存构造上，用同一部件 ID 局部更新整件质量、质心、完整惯量，再逐组核对全量重算 | 图示方案 41.90 → 43.17 kg，质心移动 30.9 mm。三个方案质心移动 25.1–30.9 mm。各组整件惯量差的 Frobenius 范数小于 9×10⁻¹⁵ kg·m²。 |
| 全量构造融合的 ADE 落后于图像先验 | 优先修尺度和部件占用，再用训练折外图像先验学习融合。分别冻结输入，逐项替换尺度、壁厚和密度，排出误差主因。 | ABO-500 当前完整方法 6.807 kg，图像先验 6.187 kg。100 件验证对象中有 65 件真值超出现有融合边界，仅靠重调权重无法消除这些误差。 |
| 首次服务器试跑加载了旧工作树的轮廓函数 | 把当前源码加入路径的动作移到依赖导入之前，独立目录重新提交 | 3 个样本的分辨率对照及 50 个对象的门控诊断均完成。 |
| MPM 连续图的共享目录中存在同名网格，且地面线型可能覆盖物体 | 用已封存的网格 SHA-256 定位坐垫原始重建。在画面中按背景、地面网格、物体排序。 | 从同一相机渲染释放、飞行、临地和接触四帧。着地后使用相同粒子与初始条件，比较预测赋值及 0.25 倍模量的响应。 |

整个恢复公式只改变几何候选。对空间点 \(x\)，\(s(x)=\min_v \tilde d_v(\pi_v(x))\)，其中 \(\tilde d_v\) 是第 \(v\) 张掩码的双线性连续有符号距离，\(\pi_v\) 是已校准投影。输入有遮挡时需要显式可见性设计。物理积分中的杆件壁厚、空腔和材料占用由独立证据约束。视觉壳生成的封闭网格本身不足以证明内部实心。

尺度偏差在均匀缩放下会按 \(s^3\) 传播至质量与按 \(s^5\) 传播至惯量。只给定外观时尺度仍可能不可识别。验证应同时报告图像估计尺度，以及通过标定或测量给定尺度的控制组。权重分歧衰减已在原验证集尝试，结果趋近图像先验且对 ADE 的配对区间跨零。 [尺度审计](../../paper_assets/abo500_20261120/validation_failure_audit.json) · [融合控制](../../paper_assets/abo500_20261120/fusion_validation/README.md)

### 机械臂如何调用部件数据

将每件物体的部件 mesh、已绑定的接触面、估计质心和惯量、材料先验及帧变换输出为资产记录。用统一的夹爪姿态搜索，根据碰撞和接触法线生成候选。根据预测质心计算重力矩 \((c-r_g)\times mg\)，用接触摩擦锥筛选满足力及力矩平衡的候选。用已校准指垫–物体摩擦获得夹持力初值，执行阶段依靠力反馈和滑移检测。测量版应记录峰值夹持力、滑移率、稳定抬升成功率和脆软物体形变。对照固定为几何规划、部件物性规划、实测物性规划。当前 MuJoCo 输出支持资产检查，实机器人试验仍待接入。

YCB 048 有扫描与 0.665 kg 目录质量，当前分配预测 0.893 kg，可用于分析体积、密度与分区误差。COCO 提供图像检测与分割输入，做斧头刚体物性实验还需要同一实物的尺度、网格和配对测量。 [YCB 目录](https://www.ycbbenchmarks.com/wp-content/uploads/2015/09/object-list-Sheet1.pdf) · [COCO](https://cocodataset.org/) · [MuJoCo 惯性参数](https://mujoco.readthedocs.io/en/latest/XMLreference.html#body-inertial)
