# 研究内容一的实验设计与证据

论文主问题是：给定固定 RGB 视角预算，能否从 mesh 获得可编辑的三维材料域和物理参数，并把同一物理状态用于质量估计和 MPM。比较以相同对象和已声明的输入协议为准。质量、材料、力学三类真值分别来源于商品质量、人工材料标注和载荷测量。

每次运行保留输入对象、视角、模型、预测封存摘要和失败日志。进入正式主表前，先在开发数据固定构造、尺寸与推理回退，再对冻结测试队列一次性评分。物性与模拟采用同一实体材料域，每种材料的积分质量须与导出的粒子质量逐项对应。
