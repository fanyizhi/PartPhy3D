# 自研Mesh构建：范围更新与可行性验证

> 状态更新：本文是同日早些时候的备选路线记录，已由 [当前执行流程](current_pipeline_2026-11-03_zh.md) 覆盖。当前采用InstantMesh固定前端；不再将自研图像重建作为首篇论文的必要条件。以下保留备选设计与科学边界。

更新：2026-11-03。用户明确要求最终方法不使用InstantMesh生成Mesh。本文记录这一约束；下述算法路线是待验证的设计，不代表已实现。

## 1. 科学定位

已有重建器作为前端不会使后续物理估计、部件编辑或减面失去作用。现在选择自研构建，是增加对几何表示和离散过程的控制，不是证明此前方法无效。编写自己的重建程序也不自动构成原创算法。

第一版限定为ABO-500提供的多视角图像、相机及可用尺度下的三维重建，不同时要求从零训练单图三维基础模型。官方Mesh只作独立几何参考/诊断输入，不能暗中用于主路径的初始化表面、包围盒、部件位置或体积支持。测试物体质量不得用于选择或调整生成几何。

InstantMesh不再是最终主路径，可在需要且预算允许时作为外部对照。现有10物体实验继续按官方参考Mesh实验报告，不改写历史来源。

## 2. 收敛后的目标路线

```text
多视角图像、相机、尺度
  → 可观测几何初始化：轮廓约束，具备条件时加入图像匹配/深度证据
  → 初始部件、材料边界与连接候选
  → 共享几何—部件—构造表示及联合更新（待设计与实现）
  → 任务约束的网格构建/稀疏化
  → 外表Mesh、独立内部材料占用场与部件身份对应
  → 原物体质量及接口兼容部件编辑
```

必须区分外表几何域和内部材料占用率。它们相关但不相同：外形封闭不表示内部实心；提取外表Mesh也不能证明恢复了内部结构。图像一致性约束主要支持可见外表，内部仍依赖构造先验和相应监督。

联合表示/更新和任务相关离散是候选技术落点，尚未确定唯一算法，也未证明改善。不要把“多视角重建＋等值面提取＋QEM”改名后作为原创贡献。

## 3. 基础技术与已有工作

轮廓交集、等值面提取和普通网格简化属于已有技术，可用于建立基线并应引用。FlexiCubes已有可微网格提取，SparseFlex已有稀疏结构等值面重建，故“自己提取”“可微”“稀疏”不是充分差异。

- [FlexiCubes作者项目](https://research.nvidia.com/labs/toronto-ai/flexicubes/)
- [SparseFlex原论文](https://arxiv.org/abs/2503.21732)

若采用这些基础算子，自己的贡献需要落在物理与部件证据如何影响几何更新、边界约束和面元预算，并有匹配预算的对照。参考标签缺失时不得宣称真实材料界面或连接已知。

## 4. 先做可行性门槛，再投入联合模型

1. 在一个固定开发物体上，仅凭图像、相机及明确尺度/场景边界约定构建几何基线，导出非退化Mesh；保存全部输入来源。
2. 用未参与拟合的视角检查轮廓/可见表面一致性；有参考Mesh时评价表面距离、法向及薄结构。仅轮廓吻合不足以验证不可见凹面。
3. 检查坐标和真实尺度、搜索域边界截断、连通分量、闭合性、体积稳定性及分辨率敏感性。缺少可验证尺度时不输出可信的绝对质量。
4. 在共享物理预测条件下，比较参考Mesh诊断、基础重建、拟议重建；评估几何误差如何传播到质量。参考Mesh输入优势单列说明。
5. 基线具有可用几何后，才实现联合部件/构造更新与局部稀疏化，比较相同面数的误差和相同误差预算的成本，再扩展固定10物体。

不得用测试质量调壁厚、密度或外形来挑选最接近标签的结果。构造/局部属性用对应真值检验，总质量吻合不能证明它们正确。

## 5. 当前实现状态

- 当前10物体由官方GLB提供几何，不能称自研图像重建结果。
- `mesh/reconstruction.py`的`GeometricImageReconstructor`根据前景统计缩放椭球，仅是合成几何基线，不是可恢复真实物体的重建器。
- 既有多视角轮廓雕刻使用参考Mesh的空间域/部件支持，尚不等于上述无参考Mesh输入的重建器。
- QEM及物理代理筛选、部件状态和质量矩代码可复用，但局部任务约束的构建/解码仍需实现。

继续保持两项核心候选贡献和一项效率候选贡献的组织，不因更换前端就直接增加第四项“原创生成”贡献。重建准确性成为新增验收条件；创新性仍依赖完整查新和实验。
